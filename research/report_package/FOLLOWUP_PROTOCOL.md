# Post-Stage-7 game-derived follow-up

Six fresh short-clock games use default eBotI and frozen v4, the same paired seeds, one worker, and the tracked collection config. Both experimental reply-slot flags are off during collection. The score is an infrastructure observation. The games supply histories for the analyses below.

- **P3 exposure.** At plies 12, 19, 26, and every seventh ply thereafter, reconstruct each player's position set from their views and their own past moves, with the existing native helper, no opponent policy, and a 4,096-state cap. Select the first three heaviest distinct, compatible hypothetical roots, never the retrospective true board. Use shared Stockfish stock tables to fix up to three common candidate actions and rank replies. At each root/action, measure how often the production selector changes a reply slot.
- **P3 decision.** Per game score the first eligible decision with a slot replacement and the first without, using identical root weights, candidates, choice formula and three reply slots. Compare actual Stockfish depth-3 continuation tables and a separately computed depth-5 reference over up to eight likely replies per state, with one continuation action per visible observation. Restrict the reference to the scored action lists. Report coverage, root changes, paired regret and measured requested/actual work. A truncated reference on a sampled belief is a diagnostic. Fixed search depth or equal reply count do not ensure equal live CPU or clock.
- **P1, P5, P9 data availability.** At the same scheduled positions, compare 64 ordinary draws versus 64 importance-weighted threat-biased draws across eight fixed seeds on the retained belief, with Brier and error against the retained-support expectation. The proposal scores hidden-attack indicators across the full retained set, so this checks estimation behavior, not computational savings. Report hidden king-attack events, realized unseen undefended non-pawn material captures and king-and-queen versus king occurrences on the fresh histories. Preserve retrospective labels as such. This audit can show whether these questions have support in this sample. Six local games are insufficient to tune a new risk model or estimate competitive prevalence.
- **Decision rule.** A useful P3 revision must change decisions, reduce reference regret on more than an isolated case, and leave a plausible equal-clock validation path. If replacement is rare, regret is unchanged or work confounds the difference, retain the old selector. Repeated tuning on this slice would reuse an evaluation set. No candidate promotion or tournament-strength claim follows from this diagnostic.

This is exploratory reuse to diagnose coverage. It also compares the unchanged Stage 4 P5 class probabilities and its training-rate constant on observed local reply outcomes, with noncaptures as the main comparison and games/paired colors as the units. No coefficients are refit.
