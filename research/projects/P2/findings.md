# P2 v1 — verified toy-algorithm findings

**Status:** executable kernel and independent hosted toy/offline record verified. **Scientific strength claim: none.**

## Distinct scientific question and mechanism

See the pre-existing [Stage 0 proposal](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/research/nine-independent-directions/research/projects/P2/proposal.md). The new module is [tools/stage3/P2.py](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/experiment/P2-v1-toy-kernel/tools/stage3/P2.py). Three softmax experts (capture, quiet and pressure) combine with a uniform action floor. Update the expert mixture using the likelihood of an observable event class, summing over indistinguishable hidden actions, then shrink toward its prior.

## Preregistered toy control

Uniform action prediction; optional fixed-style prior without online event updating.

## Measured evidence

On 180 simulated actions, retrospective mean NLL was 0.668536 versus 1.098612 uniform. Posterior mass rose to 0.929 on capture style and 0.980 on quiet style in two synthetic sequences. An event alias counterexample confirms hidden actions with the same observed effect cannot be distinguished online.

## Falsification and limitation

Uses toy action features and known event partition, not uncertainty over opponent observation in real FoW; true played move is retrospective-only target. Neither unseen-opponent generalization nor game improvement established.

## Required next experimental advance

Implement a legal-event marginalization over sampled opponent information and benchmark proper NLL on source-linked held-out games/opponents without action leakage.
