# P3 v1 — verified toy-algorithm findings

**Status:** executable kernel and independent hosted toy/offline record verified. **Scientific strength claim: none.**

## Distinct scientific question and mechanism

See the pre-existing [Stage 0 proposal](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/research/nine-independent-directions/research/projects/P3/proposal.md). The new module is [tools/stage3/P3.py](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/experiment/P3-v1-toy-kernel/tools/stage3/P3.py). For each future own observation and public-history key, choose one common feasible action maximizing weighted continuation utility; compare to a clairvoyant upper bound that independently chooses a best move in each hidden world.

## Preregistered toy control

Per-hidden-world perfect-information max, with same leaf values, and fixed baseline root fallback on deadline.

## Measured evidence

Exact two-world example: clairvoyant value 1.0, feasible contingent value 0.5, fusion gap 0.5. If future observations differ, the gap is 0.0; a root with lower clairvoyant value but higher feasible value is chosen. A zero-budget call returns the baseline action.

## Falsification and limitation

The team already had FOW_INFOSET code. This is a new independently testable exact kernel, not invention of observation grouping and not yet engine-backed FoW search; no fixed-CPU chess benefit.
