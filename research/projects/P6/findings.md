# P6 v1 — verified toy-algorithm findings

**Status:** executable kernel and independent hosted toy/offline record verified. **Scientific strength claim: none.**

## Distinct scientific question and mechanism

See the pre-existing [Stage 0 proposal](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/research/nine-independent-directions/research/projects/P6/proposal.md). The new module is [tools/stage3/P6.py](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/experiment/P6-v1-toy-kernel/tools/stage3/P6.py). Regret matching+ solves a bounded zero-sum payoff matrix, averaging iteration-weighted strategies. Compute restricted exploitability as exact best-response gap against each strategy and its worst-opponent security value.

## Preregistered toy control

Predictable pure strategy versus mixed solver; matching pennies, rock-paper-scissors, and deliberately asymmetric [[3,0],[0,1]] with known nonuniform equilibrium.

## Measured evidence

At 6,000 iterations: exact best-response gap on symmetric matching pennies 0; asymmetric game gap 0.005993 (down from 0.3856 at 10 iterations), row mix [0.2553,0.7447], column mix [0.2493,0.7507], near analytic [0.25,0.75], payoff ~0.749985 near 0.75. Pure matching-pennies security value -1 compared with near-zero mixed security.

## Falsification and limitation

This is a correct finite normal-form regret kernel, NOT the full extensive-form CFR resolver on FoW information sets. Neither blueprint preservation nor safe re-solving nor deep Stockfish leaf evaluation has been validated.

## Required next experimental advance

Build a small game with actual player observation infosets, chance reach and all feasible actions; measure restricted exploitability and equal-leaf-cost CPU against B0/deep-Stockfish controls.
