# P8 v1 — verified toy-algorithm findings

**Status:** executable kernel and independent hosted toy/offline record verified. **Scientific strength claim: none.**

## Distinct scientific question and mechanism

See the pre-existing [Stage 0 proposal](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/research/nine-independent-directions/research/projects/P8/proposal.md). The new module is [tools/stage3/P8.py](https://github.com/smhgeo422/fog-of-war-chess-bots/blob/experiment/P8-v1-toy-kernel/tools/stage3/P8.py). Define the one-step marginal value of a prospective computation from the expected post-computation maximum estimated action value minus the current maximum and a future-clock shadow price. Validate Bayesian posterior-mean consistency and enforce a non-negotiable reserve and overhead cap.

## Preregistered toy control

Skip further search in a decisive action state, compute on a near-tie state, disallow any computation whose duration breaches the reserve.

## Measured evidence

Analytic near-tie decision gain 0.1500 with a 0.5-second computation; decisive case gain 0.0. Controller chose to stop on decisive case, compute on near-tie case, and stop when reserve would be violated; false martingale update is rejected.

## Falsification and limitation

The computation-result distribution is deliberately synthetic, with no Stockfish nodes/wall timing or game clock trace. This is a correct metareasoning objective, not a demonstrated faster/stronger bot.

## Required next experimental advance

Instrument live Stockfish incremental root/depth value traces, calibrate expected VOC and actual computation costs, compare decisions and forfeits at matched total game CPU/base+increment.
